# ICCK 2027 website

Static website for the 14th International Conference on Chemical Kinetics, Milan, June 13–18, 2027.

## Local preview

Open `index.html` in a browser.

## GitHub Pages

Publish the repository on GitHub. In Settings → Pages, select Deploy from a branch, then main and / (root).

A repository named icck2027 is normally published at https://ACCOUNT.github.io/icck2027/.
For https://ACCOUNT.github.io/, the repository must be named ACCOUNT.github.io.
A custom domain can be connected later.

## Editing

- index.html: page content
- css/style.css: styles
- js/main.js: navigation
- pictures/: images

Only public website files belong in this repository. Keep committee spreadsheets and administrative documents outside it.
